# 📊 Admin Dashboard

A modern and responsive **Admin Dashboard** built with **React.js**, **Tailwind CSS**, and **React Router**.

This project is designed as a practical admin panel for managing products, users, tickets, comments, and dashboard statistics. The project focuses on component-based architecture, reusable UI components, responsive layouts, and clean React development practices.

> 🚧 **This project is currently under development.**

&nbsp;

## 🧭 Routing

Page navigation is implemented using **React Router**.

Current routes include:

```text
/
├── /Products
├── /Users
├── /Tickets
├── /Comments
├── /TicketsDetails
└── *
```

The dashboard uses a shared `DashboardLayout` for the main application structure.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Shahzadhpr/Dashboard-Admin.git
```

### 2. Navigate to the project

```bash
cd Dashboard-Admin
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Then open the local development URL provided by Vite in your browser.

&nbsp;

## 🏗️ Build for Production

To create a production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
